SAP Security, which courses should you follow?
SAP Security, which courses should you follow?
Posted by Andrea Mazzolani (translation) on Nov 4, 2022, 12:00:00 AM
Share
There are different formative paths and trainings for the SAP Security area. Below there are the main courses in the SAP Security and Governance area provided by SAP. 
Which ones would you like to follow?
1. SAP Security area (SAP roles and profiles)
ADM900 SAP System Security Fundamentals
It's a beginner overview course of the specific ADM940, ADM950 and ADM960 courses
ADM910 - Compliant User Lifecycle Management for SAP S/4HANA and SAP Business Suite
This course lets you understand how to manage the conformity to the main regulations and norms on the users life cycle management
ADM940 AS ABAP – Authorization Concept
This course lets you understand how the authorization concept works in SAP
ADM945 SAP S/4HANA – Authorization Concept
It's a dedicated course on authorizations specific for S/4HANA
ADM950 Secure SAP System Management
It's a course intended for revisors and internal audits
ADM960 SAP NetWeaver Application Server Security
It's a course for system administrators, contrary to the above where the applicative security of the product is treated, this course emphasizes the infrastructural aspects of SAP, SAP cyber security
BW465 User Management and Authorizations
This course details the authorizations for data analysis systems. It's the ADM940 counterpart in the ERP environment
HR940 Authorizations in HCM
This course details the SAP authorizations specific for the SAP HR and HCM environnement
2. HANA Database Security
HA240 SAP HANA 2.0 SPS04 - Authorizations, Scenarios & Security Requirements
This course details the security and authorization management in the SAP HANA database
3. SAP Governance Risk and Compliance and GDPR Area
GRC100 GRC Principles and Harmonization
It's an introduction course in the SAP GRC area, including GRC Access Control, Process Control and Risk Management
GRC300 SAP Access Control Implementation and Configuration
This course details how to configure and install the GRC Access Control product
GRC330 SAP Process Control 12.0 Implementation and Configuration
This course details how to configure and install the GRC Process Control product
GRC340 SAP Risk Management 12.0
This course details how to configure and install the GRC Risk Management product
GRC350 SAP Business Integrity Screening (BIS)
This course details how to configure and use the SAP Fraud Management product
BIT665 SAP Information Lifecycle Management (ILM)
It's one of the essential tools in the SAP drawing for the GDPR management
It describes how to activate and use the Information Lifecycle Management module
Aglea provides teachers to SAP Italy for the SAP Security and Governance area!
4. Area Identity and Access Management
ADM920 SAP Identity Management
This course details how to configure and use the SAP Identity Management product
5. Which should you do before and after?
The ADM900 and GRC100 introduction courses can be a good starting point to get an idea of how SAP Security should and is managed. Statistically the most frequent courses of the above area are:
GRC300/ADM940
ADM950
